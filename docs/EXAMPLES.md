# CoreContext Examples

## Example 1: Basic Usage

```bash
# Scan current project, save to context.md
corecontext prune --dir . --output context.md
```

Output:
```
Scanning: /path/to/project
Found 12 Python files. Building graph...

Files: 12
Original: 15,234 tokens
Pruned:   2,891 tokens
Saved:    12,343 tokens (81.0%)
```

## Example 2: Keep Critical Functions

```bash
# Keep main() and setup() intact, prune others
corecontext prune --dir . --critical main --critical setup --output slim.md
```

Critical functions keep their full body:
```python
def main():
    # Entire implementation preserved
    setup()
    process_data()

def setup():
    # Entire implementation preserved
    logger.debug("Starting")
    ...
```

Non-critical functions become stubs:
```python
def helper():
    ...

def utility():
    ...
```

## Example 3: Aggressive Pruning

```bash
# Strip prints, remove logging, prune __init__, optimize everything
corecontext prune --dir . \
    --strip-print \
    --prune-init \
    --no-optimize-imports=false \
    --output aggressive.md
```

Savings typically 90%+.

## Example 4: Selective Exclusion

```bash
# Generate context excluding tests and docs
corecontext prune --dir . \
    --exclude "tests/" \
    --exclude "docs/" \
    --exclude "*.md" \
    --output prod_context.md
```

## Example 5: Piping to LLM

```bash
# Generate ultra-minimal context for Claude
corecontext prune --dir . --output - | \
    wc -l  # Count output lines
```

Result: Get the context file for pasting into an LLM.

## Tips & Tricks

### Avoid Over-Pruning

```bash
# Bad: Removes too much structure
corecontext prune --no-optimize-imports --prune-init

# Good: Keep essentials, remove boilerplate
corecontext prune --critical __init__
```

### Chain Multiple Criticals

```bash
corecontext prune --dir . \
    --critical main \
    --critical __init__ \
    --critical setup_database \
    --critical authenticate_user \
    --output context.md
```

### Exclude Common Patterns

```bash
corecontext prune --dir . \
    --exclude "**/test_*.py" \
    --exclude "**/conftest.py" \
    --exclude "**/__pycache__/*" \
    --exclude "venv/" \
    --output clean.md
```

### For Web Projects

```bash
# Exclude frontend build artifacts
corecontext prune --dir . \
    --exclude "node_modules/" \
    --exclude "dist/" \
    --exclude "build/" \
    --output backend_context.md
```
